# Independent certificate testing theory

The native certificate shelf previously covered DB/SQL only. This release adds
three connected public reading lessons: partition/boundary selection, explicitly
counted statement/control-flow execution, and test oracle/confirmation/regression.
The first12 lessons, example data, IDs, checklist text and backup version1/key
are unchanged apart from additive domain metadata. The shared renderer now uses
domain labels and accurate verification captions; JS examples do not show the
common SQL dataset or claim PGlite execution. No browser code runner is added.

Source audit: concepts-theory.json was read-only and its SHA256 was checked
against the existing provenance. Four concept IDs and their original primary
reference links are retained. A similarly named theory.json identifies itself
as reconstructed questions and was excluded. No question banks, recalled code,
solutions, original diagrams or images are imported. New loan-day contracts,
JavaScript, tables, graph, recall prompts and explanations are independently
authored. Existing origin/license notices are preserved; source ownership is
acknowledged. This is not accredited training or current exam-policy coverage.

The boundary case accepts numeric integers1..21 without coercion. Its six
selected values around the valid endpoints are an authored selection, not a
claim of full two-/three-value BVA coverage under a particular syllabus. Extra
float and string cases expose the type contract. Eight displayed outcomes and
81 integers(-40..40), plus10 type/nonfinite samples are verified against a
separately enumerated allowed set.

The fixed Boolean example marks S1/S2/S3 as three counted action statements;
D1 is a separate decision node excluded from that marked-statement count.
The graph includes entry/exit and six conditional/unconditional edges:
start-S1-D1-S2-S3-end or start-S1-D1-S3-end. All four subsets of the two Boolean
inputs are instrumented from the actual displayed code. True-only visits3/3
marked statements and5/6 edges; false-only2/3 and4/6; both3/3 and6/6. These are
declared model counts, not a claim that every coverage tool uses these items.
A21-to20 mutation keeps full graph execution but fails the independent policy
oracle. D1 outcome-only coverage, condition coverage and MC/DC are not conflated
with the graph's full-edge denominator.

The before/after pure-function example fixes <21 to <=21. The corrected21 case
and unchanged0/1/22/string cases match the independently stated contract. Real
date handling, authorization, database operation and cross-system regression are
outside these finite demonstrations. Existing SQL result checks remain separate.

Validation also covers the previous complete12-lesson record plus new notes,
mixed version1 backup roundtrip/merge and same-note conflicts. Actual desktop QA
must cover domain labels, all three routes, code/table/graph reading at22px,
old notes retained, new note/check/review reload, shared resume, backup download
and restoration, no-JS content and no account network writes. Production DB
migration, OAuth and account activation remain outside this bundle.
