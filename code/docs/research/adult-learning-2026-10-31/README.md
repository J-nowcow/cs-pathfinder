## 조사 범위와 결론

공개 문서 51개(참조 레코드 55개), 교육 서비스·프로젝트 11개, 공개 경험담·이슈 스레드 8개를 검토했다. 동일 문서의 댓글·URL 조각은 독립 문서로 중복 계산하지 않았다. 인터넷 전수조사나 PRISMA 체계적 문헌고찰은 아니다. 인터뷰 없이 공개 근거로 설계 우선순위를 정하는 작업이다.

**기존 개념 자료를 기반으로, 근거를 읽고 판단을 수정한 다음 새로운 조건에 적용하는 대표 모듈 하나부터 만든다.** 실습·사례·시뮬레이션은 기존 서비스에도 있다. 차별화 가설은 사실, 적용 조건, 역할별 질문, 판단의 변화, 후속 과제를 얼마나 잘 연결하는지에 있다. 세계 최초나 수요·효과 검증을 주장하지 않는다.

| 설계 결정 | 근거 | 적용 한계 |
|---|---|---|
| 짧게 시작하고 다시 떠올릴 기회를 제공 | R01, R26, R27 | 짧은 콘텐츠만으로 복잡한 역량이 완성되지는 않음 |
| 초기 판단을 설명에 연결하고 풀이 시범을 선택 가능하게 제공 | R02, R03, R04 | 학생·기초과학 연구를 모든 성인 직무에 일반화하지 않음 |
| 외부 도움을 받은 산출물과 도움 없이 작성한 답안을 구분 | R06–R09 | 연구별 조건·결과가 다름. 미출판 논문과 동료 심사 논문 구분 |
| 개발자·프로젝트 PM·제품 PM의 질문과 점검 기준 분리 | R10–R14, R24 | 역할 수요 설문은 표본 편향이 있고 개인별 과업을 대표하지 않음 |
| 원문 사실·교육용 가정·작성자의 해석 구분 | R22–R24 | 사후 보고서가 당시 의사결정 정보를 모두 제공하지 않음 |
| 작은 기여 단위와 출처·버전 추적 | A11, A14, B04 | 제작·검토·번역 비용은 실제 작업 시간으로 후속 측정 필요 |

근거 ID의 URL·열람 범위·한계는 출처 원장에 있다. R05는 초록·서지, R13·R14·R27은 공개 요약 위주이며 본문 전체를 읽은 자료처럼 취급하지 않았다. 서비스 소개는 기능 존재를 확인하는 자료이며 독립적인 학습 효과 증거가 아니다. 공개 경험담은 문제 발견용이고 발생 빈도 추정용이 아니다.

## 토론에서 남긴 조건

D3-lite 2라운드에서 개념 기반 접근과 판단 과제 접근을 비교했다. `advocate-*-round2.json`은 각각의 최종 논증이다. 정량 효과나 시장 크기 자료가 없어 임의 점수는 만들지 않았다.

- 개념 자료와 실무 과제의 연결을 유지한다.
- 초보자가 먼저 예시를 보거나 필요한 개념을 읽을 수 있어야 한다.
- 자동 채점·완료율을 실제 직무 역량으로 부르지 않는다.
- 사람의 무제한 무료 멘토링을 기본 운영 조건으로 두지 않는다.
- 검토받지 않은 작성 예시를 전문가 정답이나 공식 대응 절차로 표시하지 않는다.
