# 도식 고르기 시험 — 질문 12개

각 질문에 답하는 해설을 쓴다면 **어떤 도식 울타리를 쓸 것인가.**

1. TCP 연결은 어떤 상태를 거쳐 끊기는가?
2. 두 스레드가 같은 잔액을 동시에 고치면 무슨 일이 생기는가?
3. 프로세스 주소 공간은 어떻게 나뉘는가?
4. B-tree의 노드는 어떻게 이어져 있는가?
5. OSI 7계층은 무엇을 나누는가?
6. 낙관적 락과 비관적 락은 무엇으로 고르는가?
7. HTTPS 요청 하나가 오갈 때 무슨 일이 순서대로 일어나는가?
8. 서킷 브레이커는 어떤 상태를 오가는가?
9. 블로킹 입출력에서 스레드는 무엇을 하며 기다리는가?
10. 자바 예외 클래스는 어떻게 갈라지는가?
11. 스택 오버플로는 왜 나는가?
12. 데드락은 어떤 순간에 성립하는가?
