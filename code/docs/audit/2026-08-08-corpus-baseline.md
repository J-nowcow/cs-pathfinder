# 지금 무엇이 있는가 — 기준선

2026-08-08 측정. `npm run measure:corpus`로 저장된 `qnode.body` 277편을 전수로 셌다. 표본이 아니다.

## 한 줄

**표만 있는 해설이 136편, 전체의 49.1%다.** 사용자가 "죄다 표만 있고 그림은 하나도 없다"고 한 것의 정확한 크기다.

## 무엇이 붙어 있나

한 편에 하나씩이다 — 136+74+64+1+1 = 276, 통짜 글 1편을 더하면 277.

읽는 법 셋.

**표는 펜스로 안 온다.** `:::table`이 0건인데 표는 136건이다. 파서에 `table` 종류가 있지만 저장된 본문은 전부 그냥 마크다운 파이프 표다. **펜스만 세면 "표가 없다"는 거짓 그림이 나온다.**

**`state`가 딱 1편이다.** 파서에 있고 렌더러도 있는데 아무도 안 쓴다. TCP 상태 기계 같은 것이 표로 그려져 있다는 뜻이다.

**`memory`·`timeline`이 0건이다.** 렌더러가 있는데 생성분에 한 번도 안 나왔다. 있는 것과 쓰이는 것은 다르다.

## 앞선 보고와 어긋나는 곳

`docs/plan/2026-08-07-priorities.md`가 "도식 채택률 100%"라고 적었다. 여기서는 49.1%가 표뿐이다. **둘 다 맞다 — 다른 것을 쟀다.**

- 그쪽은 `measure:diagrams`다. Gemini로 몇 편을 새로 만들어 **프롬프트가 지금 무엇을 내놓는지** 본다
- 이쪽은 이미 저장된 것을 읽어 **독자가 실제로 보는 것**을 본다

프롬프트를 고쳐도 저장된 본문은 다시 만들지 않으므로 둘은 갈라진다. **독자가 보는 것은 이쪽이다.**
