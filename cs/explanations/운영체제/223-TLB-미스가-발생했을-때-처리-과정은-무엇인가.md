# TLB 미스가 발생했을 때 처리 과정은 무엇인가?

`#223` · 운영체제

가상 주소를 물리 주소로 변환하는 과정에서 TLB에 정보가 없으면 페이지 테이블로 이동한다. 이후 메모리에서 페이지 테이블 엔트리를 찾아 주소 변환을 완료한다.

1. **가상 주소 → TLB** — 주소 변환 요청
2. **TLB → 메모리** — TLB 미스 발생, 페이지 테이블 참조
3. **메모리 → CPU** — 물리 주소 반환

TLB는 주소 변환 속도를 높이기 위한 캐시이다. 페이지 테이블은 메인 메모리에 저장되어 있어 접근 속도가가 느리다. 따라서 TLB에 정보가 없으면 메모리에 두 번 접근해야 하므로 성능이 저하된다.

컨텍스트 스위칭이 발생하면 이전 프로세스의 TLB 정보는 더 이상 유효하지 않는다. 이때 TLB를 모두 비우는 플러시로 성능을 저하 시킨다. ASID를 사용하여 프로세스별로 정보를 구분하여 플러시를 줄이는 방식이 대안이다.
