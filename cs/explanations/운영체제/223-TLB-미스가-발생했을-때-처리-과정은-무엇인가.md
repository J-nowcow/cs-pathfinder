# TLB 미스가 발생했을 때 처리 과정은 무엇인가?

`#223` · 운영체제

가상 주소를 물리 주소로 변환하는 과정에서 TLB에 정보가 없으면 페이지 테이블로 이동한다. 이후 메모리에서 페이지 테이블 엔트리를 찾아 주소 변환을 완료한다.

1. **가상 주소 → TLB** — 주소 변환 요청
2. **TLB → 메모리** — TLB 미스 발생, 페이지 테이블 참조
3. **메모리 → CPU** — 물리 주소 반환

TLB는 주소 변환을 빨리 하려고 두는 캐시다. 페이지 테이블은 메인 메모리에 있어 보러 가는 것이 느리다.

TLB에 없으면 페이지 테이블을 타고 내려간 뒤에야 데이터에 닿는다. 단계가 여러 겹이면 그만큼 더 걸리고, 페이지가 아예 없으면 페이지 폴트로 이어진다.

컨텍스트 스위칭이 일어나면 앞 프로세스의 TLB 항목은 더 이상 맞지 않는다.

주소 공간에 꼬리표를 못 다는 시스템이면 전환할 때 TLB를 비운다. PCID나 ASID가 있으면 프로세스별로 갈라 두므로 앞 항목을 남긴다.
