# 프로세스 주소 공간을 나누는 이유는 무엇인가?

`#176` · 운영체제

프로세스 간의 메모리 침범을 막고 효율적으로 자원을 관리하기 때문이다.

위가 높은 주소, 아래가 낮은 주소다.

| 영역 | 설명 | 방향 |
| --- | --- | --- |
| 스택 | 지역 변수, 함수 호출 정보 | 아래로 자란다 |
| 힙 | 동적 할당 영역 | 위로 자란다 |
| 데이터 | 전역 변수, 정적 변수 |  |
| 코드 | 프로그램 실행 파일의 기계어 |  |

위 도식은 프로세스가 사용하는 메모리 영역의 일반적인 구조를 보여준다.

코드 영역은 읽기 전용으로 설정하여 프로그램 실행 파일의 내용을 그대로 올린다. 데이터 영역은 프로그램 시작부터 종료까지 유지되는 상태를 저장한다.

힙은 런타임에 크기가 결정되는 동적 메모리 영역이다. 스택은 함수 호출 시 생성되고 종료 시 사라지는 임시 저장소다.

두 영역은 서로 반대 방향으로 성장하며 충돌을 방지한다. 이렇게 영역을 나누면 메모리 보호와 가상 메모리 관리가 용이해진다.
