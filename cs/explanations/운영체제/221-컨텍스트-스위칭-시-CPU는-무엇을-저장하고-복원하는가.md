# 컨텍스트 스위칭 시 CPU는 무엇을 저장하고 복원하는가?

`#221` · 운영체제

현재 실행 중인 프로세스의 상태 정보인 PCB로 상태를 저장하고, 다음으로 실행할 프로세스의 PCB에서 상태를 복원한다.

위가 위층이다.

| 층 | 설명 |
| --- | --- |
| PCB | 프로세스 제어 블록. 상태, PC, 레지스터 값 저장 |
| CPU 레지스터 | 현재 연산으로 사용 중인 실제 물리적 값 |

상태 저장 시 CPU의 프로그램 카운터(PC)과 레지스터 값들이 PCB에 옮겨진다. 그래야 나중에 다시 돌아왔을 때 중단된 지점부터 정확히 연산으로 돌아갈 수 있다.

이후 스케줄러가 선택한 다음 프로세스의 PCB를 읽어 CPU 레지스터에 값을 덮어쓴다. 이 과정에서 CPU는 어떤 실제 연산을 수행하지 않는 것을 오버헤드로 본다.

캐시 메모리나 TLB 같은 메모리 캐시가 무효화되는 비용이 발생하는 점이 중요하다. 단순한 레지스터 복원보다 이 캐시 초기화 비용이 더 크다.
