# CPU 스케줄러의 단계별 역할은 무엇인가?

`#193` · 운영체제

프로세스의 상태 변화와 실행 우선순위에 따라 실행 주기와 대상자를 정하는 역할이다.

| 스케줄러 | 역할 |
| --- | --- |
| 장기 | 작업 큐에서 메모리로 올릴 프로세스 결정 |
| 중기 | 메모리 부족 시 일부를 디스크로 내보냄 |
| 단기 | 준비 큐에서 CPU를 할당할 프로세스 선택 |

위 도식은 각 스케줄러가 결정하는 범위와 시간적 단위를 보여준다. 장기 스케줄러는 시스템의 다중 프로그래밍 정도를 조절하며, 단기 스케줄러는 밀리초 단위로 빠르게 동작한다.

중기 스케줄러는 스와핑을 통해 메모리 효율을 높인다. 메모리가 부족하면 프로세스를 잠시 디스크로 내려 물리 메모리 자리를 확보한다.

단기 스케줄러는 실제 CPU 점유를 결정하므로 응답 시간과 처리량에 가장 큰 영향을 미친다. 문맥 교환 비용을 최소화하는 것이 핵심이다.
