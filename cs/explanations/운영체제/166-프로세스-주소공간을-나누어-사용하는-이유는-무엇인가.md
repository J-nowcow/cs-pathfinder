# 프로세스 주소공간을 나누어 사용하는 이유는 무엇인가?

`#166` · 운영체제

프로세스 간의 간섭을 막고 메모리 관리를 효율적으로 하기 위해서다.

위가 높은 주소, 아래가 낮은 주소다.

| 영역 | 설명 | 방향 |
| --- | --- | --- |
| 스택 | 지역 변수, 함수 호출 정보 | 아래로 자란다 |
| 힙 | 런타임에 할당되는 동적 메모리 | 위로 자란다 |
| 데이터 | 전역 변수, 정적 변수 |  |
| 코드 | 프로그램 실행 파일의 기계어 |  |

위 구조는 메모리 활용 목적에 따라 영역을 구분한 것이다. 각 영역은 데이터의 성격과 생명주기가 다르기에 분리하여 관리한다.

흔한 배치에서는 스택과 힙이 서로 마주 보고 자란다. 어느 쪽이 어디서 시작하는지는 운영체제와 규약에 따라 다르다. 두 영역이 서로 마주 보고 자라게 하여 가용 공간을 유동적으로 공유한다.

가상 메모리 기법을 통해 각 프로세스는 독립된 주소공간을 가진다. 이를 통해 한 프로세스의 오류가 다른 프로세스의 메모리를 오염시키는 것을 방지한다.
