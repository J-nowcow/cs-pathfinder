# 급한 일이 안 급한 일에 밀리는 경우가 있는가?

`#319` · 운영체제

있다. 급한 쪽이 기다리는 잠금을 안 급한 쪽이 쥐고 있는데, 그 안 급한 쪽마저 다른 일에 밀릴 때다.

|  | 급한 일 | 중간 일 | 느린 일 |
| --- | --- | --- | --- |
| 1 |  |  | 잠금을 쥔다 |
| 2 | 잠금을 기다린다 |  |  |
| 3 | 계속 기다린다 | 끼어들어 돈다 | 밀려서 못 끝낸다 |
| 4 | 받는다 | 끝난다 | 놓는다 |

급한 일은 느린 일이 잠금을 놓기만 기다린다. 그런데 느린 일은 중간 일에 밀려 돌지 못한다. **결국 급한 일이 중간 일에 밀린 셈**이 된다.

이름이 역전인 이유가 거기 있다. 우선순위대로면 일어날 수 없는 순서가 만들어진다.

푸는 방법은 잠금을 쥔 쪽의 우선순위를 잠깐 올리는 것이다. 급한 쪽만큼 올려 주면 중간 일이 끼어들지 못한다.

화성 탐사선 패스파인더가 이것으로 계속 재시작했다. 지구에서 우선순위 상속을 켜는 설정을 올려 고쳤다.
