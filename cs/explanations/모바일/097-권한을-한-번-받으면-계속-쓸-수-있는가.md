# 권한을 한 번 받으면 계속 쓸 수 있는가?

`#97` · 모바일

계속 쓸 수 있다고 가정하면 안 된다. 사용자가 철회할 수 있고 일회성 권한과 자동 초기화도 있다. 보호 기능을 쓰기 직전에 상태를 다시 확인해야 한다.

1. **앱 → 시스템** — 현재 권한 상태를 확인한다
2. **시스템 → 사용자** — 필요한 시점에 동의를 요청한다
3. **사용자 → 시스템** — 허용하거나 거부한다
4. **시스템 → 앱** — 결과를 전달한다

매니페스트 선언은 그 권한을 쓰겠다는 예고다. 일반 권한은 그것만으로 설치할 때 붙고, 위험 권한만 실행 중에 따로 물어야 한다. 위험 권한은 실행 중 동의를 받아야 하며 최소 범위만 기능 맥락 안에서 요청해야 한다.

거부 뒤 다시 요청할 수 있는지는 시스템 상태에 달렸다. 설명 화면과 설정 이동을 구분하고 거부되어도 핵심 기능이 무너지지 않게 설계한다.

사진 선택기처럼 권한 없이 목적을 달성하는 시스템 기능을 우선한다. 권한 범위가 줄수록 개인정보 위험과 심사 부담도 줄어든다.
