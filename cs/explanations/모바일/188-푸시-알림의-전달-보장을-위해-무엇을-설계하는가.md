# 푸시 알림의 전달 보장을 위해 무엇을 설계하는가?

`#188` · 모바일

푸시 서버와 FCM/APNs 같은 외부 플랫폼의 전송 상태를 추적하고 재시도 메커니즘을 구현한다.

1. **푸시 서버 → 플랫폼** — 메시지 전송 요청
2. **플랫폼 → 푸시 서버** — 수신 확인(ACK) 응답
3. **푸시 서버 → 플랫폼** — 실패 시 지수 백오프 재시도

전송 요청 후 플랫폼에서 주는 응답만으로는 실제 단말기 도달 여부를 알 수 없다. 플랫폼이 메시지를 큐에 넣었을 때 성공으로 응답하기 때문이다.

따라서 단말기가 알림을 수신했을 때 서버로 수신 확인 신호를 보내는 피드백 루프를 설계한다. 이를 통해 누락된 알림을 다시 보낼 수 있다.

메시지 ID를 통해 중복 수신을 방지하는 멱등성 처리도 함께 고려해야 한다. 네트워크 불안정으로 인한 재시도 시 동일 알림이 여러 번 뜰 수 있다.
