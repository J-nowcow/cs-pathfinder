# 인덱스 범위 스캔과 전체 스캔 중 무엇을 선택하는가?

`#254` · 데이터베이스

데이터의 선택도와 비용 옵티마이저의 판단에 따라 결정한다. 읽어야 할 데이터가 전체의 일정 비율을 넘으면 인덱스보다 전체 스캔이 빠르다.

| 기준 | 인덱스 범위 스캔 | 전체 스캔 |
| --- | --- | --- |
| 접근 방식 | B-Tree 탐색 후 리프 노드 순회 | 데이터 페이지 순차 읽기 |
| 효율성 | 소량 데이터 추출 시 유리 | 대량 데이터 추출 시 유리 |
| I/O 방식 | 랜덤 I/O 발생 | 순차 I/O 발생 |

인덱스 범위 스캔은 인덱스 페이지를 거쳐 데이터 페이지로 이동하는 랜덤 I/O가 발생한다. 읽을 양이 많아지면 이 오버헤드가 순차적으로 읽는 전체 스캔보다 커진다.

옵티마이저는 통계 정보를 바탕으로 비용을 계산한다. 인덱스를 통해 읽어야 할 페이지 수가 전체 페이지 수의 상당 부분을 차지하면 전체 스캔을 선택한다.

실무에서는 통계 정보가 오래되었을 때 엉뚱한 스캔 방식이 선택되어 성능이 급락한다. 이때는 힌트를 사용해 강제로 실행 계획을 변경해야 한다.
