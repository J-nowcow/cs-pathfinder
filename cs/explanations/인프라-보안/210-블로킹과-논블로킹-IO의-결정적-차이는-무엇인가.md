# 블로킹과 논블로킹 I/O의 결정적 차이는 무엇인가?

`#210` · 인프라 · 보안

제어권의 반환 시점이다. 블로킹은 작업 완료까지 기다리며, 논블로킹은 호출 즉시 제어권을 돌려준다.

|  | 블로킹 호출자 | 논블로킹 호출자 |
| --- | --- | --- |
| 1 | 읽기를 부른다 | 읽기를 부른다 |
| 2 |  | `EAGAIN`으로 바로 돌아온다 |
| 3 |  | 다른 일을 한다 |
| 4 | 데이터를 받는다 | 데이터를 받는다 |

위 그림에서 블로킹 호출자의 빈 칸이 멈춰 있는 시간이다. 코드는 직관적이지만 그동안 스레드가 아무것도 못 한다.

논블로킹은 대기 시간 동안 다른 일을 할 수 있다. 대신 작업 완료 여부를 계속 확인하거나 알림을 받아야 하므로 로직이 복잡해진다.

이 구분은 동기/비동기 개념과 섞이기 쉽다. 핵심은 '제어권'이 누구에게 있는지에 주목해 구분해야 한다.
