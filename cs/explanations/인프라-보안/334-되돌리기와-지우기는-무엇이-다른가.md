# 되돌리기와 지우기는 무엇이 다른가?

`#334` · 인프라 · 보안

되돌리기는 무르는 기록을 하나 더 얹는다. 지우기는 가지가 가리키는 자리를 뒤로 옮겨 그 뒤 기록을 이력에서 뺀다. 남과 나눈 뒤라면 이 차이가 크다.

|  | 되돌리기 | 지우기 |
| --- | --- | --- |
| 1 | A | A |
| 2 | B | B |
| 3 | C |  |
| 4 | C를 무르는 D |  |

혼자 쓰는 가지라면 지워도 된다. 기록이 깔끔해진다.

**남이 이미 받아 간 가지라면 다르다.** 지우면 남의 기록과 내 기록이 갈라진다. 남은 없어진 것을 붙들고 있고 다음 합칠 때 충돌한다.

그래서 나눈 뒤에는 되돌리기를 쓴다. 무르는 기록이 하나 더 생기지만 남의 것과 어긋나지 않는다.

면접에서는 **되돌린 기록도 남는다**는 점을 짚는다. 비밀번호를 실수로 올렸다면 되돌리기로는 안 지워진다. 그때는 기록 자체를 다시 써야 하고, 이미 나갔다면 그 비밀번호를 바꾸는 것이 먼저다.
