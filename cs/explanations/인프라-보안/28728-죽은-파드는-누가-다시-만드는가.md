# 죽은 파드는 누가 다시 만드는가?

`#28728` · 인프라 · 보안

상위 컨트롤러가 만든다. Deployment나 ReplicaSet이 원하는 개수와 지금을 견주고 모자란 만큼 채운다.

1. **사용자 → API 서버** — 파드를 셋 두라고 적는다
2. **API 서버 → 컨트롤러** — 하나가 사라졌다고 알린다
3. **컨트롤러 → API 서버** — 하나 더 만들라고 적는다

요점은 **명령이 아니라 상태를 적는다**는 것이다. "파드를 만들어라"가 아니라 "셋이어야 한다"를 남기고, 그 차이를 메우는 일은 컨트롤러가 되풀이한다.

컨트롤러는 매번 묻지 않는다. API 서버가 바뀔 때마다 알려주고, 컨트롤러는 그것을 모아 둔 사본을 기준으로 맞춘다.

예외가 둘 있다. 상위 컨트롤러 없이 만든 파드는 사라지면 그만이다. 컨테이너만 죽은 경우에는 kubelet이 같은 파드 안에서 다시 띄운다.
