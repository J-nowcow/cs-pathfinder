# 컨테이너 이미지를 최소화해야 하는 이유는 무엇인가?

`#302` · 인프라 · 보안

공격 표면을 줄여 보안성을 높이고 이미지 크기를 줄여 배포 속도를 높이기 때문이다.

| 효과 영역 | 최소화 효과 |
| --- | --- |
| 보안 | 불필요한 셸, 패키지 관리자 제거로 침투 경로 차단 |
| 배포 | 레이어 크기 감소로 네트워크 전송 및 풀링 속도 향상 |
| 운영 | 취약점 스캔 결과의 노이즈를 줄여 관리 효율 증대 |

이미지 내에 셸이나 curl 같은 도구가 많을수록 해커가 침투 후 내부망을 탐색하거나 추가 악성 코드를 설치하기 쉽다. Distroless 이미지는 실행 파일과 런타임만 포함해 이런 도구를 원본적으로 차단한다.

최소 이미지 전략은 저장 공간과 내려받는 양을 줄인다. 빌드 시간은 오히려 늘 수 있다. 다단계 빌드가 한 단계를 더 도는 탓이다. 특히 오토스케일링 환경에서 노드에 이미지를 빠르게 풀링하는 것은 서비스 가용성에 직결된다.
