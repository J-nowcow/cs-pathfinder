# 이미지를 고쳐도 조금만 받는 이유는?

`#28729` · 인프라 · 보안

층마다 고유한 지문이 있어 이미 가진 층은 안 받기 때문이다. 바뀐 층만 새로 내려온다.

위가 위층이다.

| 층 | 설명 |
| --- | --- |
| 내 앱 코드 | 커밋마다 바뀐다. 대개 이 층만 다시 받는다 |
| 의존성 설치 | 잠금 파일이 바뀔 때만 |
| 런타임 | 버전을 올릴 때만 |
| 베이스 이미지 | 여러 이미지가 함께 쓴다 |

만들 때는 다른 이야기다. 한 명령에서 캐시를 못 쓰면 **그 명령과 뒤따르는 명령이 전부 다시 실행된다.** 그래서 자주 바뀌는 것을 뒤에 둔다.

앱 코드를 먼저 복사하면 그 뒤 설치 명령이 매번 다시 돈다. 순서 하나로 빌드 시간이 갈린다.

지운 파일도 아래층에 남는다. 비밀값을 넣었다가 다음 층에서 지워도 이미지 안에는 그대로 있다.
