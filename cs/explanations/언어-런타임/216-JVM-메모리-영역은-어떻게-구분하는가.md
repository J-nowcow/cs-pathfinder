# JVM 메모리 영역은 어떻게 구분하는가?

`#216` · 언어 · 런타임

런타임 데이터 영역으로 구분하며, 스레드 간 공유 여부에 따라 공유 영역과 개별 영역으로 나눈다.

- **공유 영역** — 모든 스레드가 함께 쓴다
  - **Heap**
  - **Method Area**
- **개별 영역** — 스레드마다 따로 생긴다
  - **Stack**
  - **PC Register**
  - **Native Method Stack**

공유 영역은 모든 스레드가 접근 가능하다. 가비지 컬렉션의 대상이 되어 메모리 관리가 자동화된다.

개별 영역은 스레드 생성 시 함께 생성되고 종료 시 사라진다. 스레드만 접근하므로 동기화 문제가 발생하지 않는다.
