# 헬스 체크는 어떤 조건을 검사하는가?

`#309` · 네트워크

헬스 체크는 IP 도달성, TCP 포트 개방, HTTP 응답 코드와 애플리케이션 내부 상태를 검사한다. 계층에 따라 검사 대상과 깊이가 달라진다.

위가 위층이다.

| 층 | 설명 |
| --- | --- |
| L7 헬스 체크 | HTTP 200 OK, DB 연결, 내부 의존성 상태 |
| L4 헬스 체크 | TCP 소켓 연결(SYN/ACK) 성공 여부 |
| L3 헬스 체크 | ICMP Ping 응답으로 네트워크 도달 확인 |

위와 같이 로드 밸런서는 계층별로 다른 조건으로 서버 상태를 판단한다. 단순한 네트워크 생존부터 실제 서비스 처리 가능 여부까지 확인한다.

L3과 L4 검사는 단순하고 빠르다. 하지만 프로세스가 밀려서 멈추거나 DB 연결이 끊겨도 성공으로 처리하는 한계가 있다.

L7 검사는 특정 엔드포인트로 요청을 보내 내부 자원 상태까지 확인한다. 대신 검사 주기가 짧으면 서버 자체에 부담을 준다.
