# HTTP 상태 코드는 어떤 기준으로 분류하는가?

`#179` · 네트워크

첫 번째 자리 숫자가 응답의 성격으로 분류된다. 1xx는 정보, 2xx는 성공, 3xx는 리다이렉션, 4xx는 클라이언트 오류, 5xx는 서버 오류다.

| 상태 코드 | 분류 |
| --- | --- |
| 1xx | 정보 제공 |
| 2xx | 성공적인 처리 |
| 3xx | 리다이렉션 |
| 4xx | 클라이언트 요청 오류 |
| 5xx | 서버 내부 오류 |

위 표는 숫자의 첫 자리만으로도 로그 분석이나 모니터링 도구에서 빠르게 판단하는 기준이 된다.

4xx와 5xx의 차이는 책임 소재가 어디에 있느냐다. 4xx는 요청 쪽 사정으로 서버가 처리하지 못했다는 뜻이다. 고쳐 보내면 되는 것도 있고 인증이나 한도처럼 그렇지 않은 것도 있다. 5xx는 요청은 멀쩡한데 서버가 못 해냈다는 뜻이다.
