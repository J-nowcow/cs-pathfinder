# 브라우저에 URL을 입력하면 어떤 과정을 거치는가?

`#225` · 네트워크

DNS로 IP를 찾고 연결을 맺은 뒤 요청과 응답을 주고받는 과정이다. 연결은 HTTP 버전에 따라 TCP일 수도 QUIC일 수도 있다.

1. **브라우저 → DNS** — 도메인으로 IP 조회
2. **DNS → 브라우저** — IP 주소 반환
3. **브라우저 → 서버** — TCP 3-Way Handshake
4. **브라우저 → 서버** — HTTP 요청
5. **서버 → 브라우저** — HTTP 응답

먼저 브라우저와 OS로 부터 캐시된 IP를 확인한다. 없으면 DNS 서버에 재귀적으로 요청하여 서버의 IP 주소를 알아낸다.

그 후 연결을 맺는다. HTTP/1.1과 HTTP/2는 TCP로 세 번 악수하고, HTTP/3은 UDP 위의 QUIC을 쓴다. HTTPS의 경우 TLS Handshake 과정이 추가되어 데이터 암호화 세션을 구축한다.

마지막으로 HTTP 요청 메시지를 생성해 전송하고, 서버는 이를 처리해 HTML 문서와 같은 리소스를 반환한다. 브라우저는 이를 렌더링하여 화면에 표시한다.
