# 전송 계층에서 멀티플렉싱과 디멀티플렉싱은 무엇으로 구분하는가?

`#169` · 네트워크

포트 번호를 통해 구분한다. 하나의 IP 주소로 들어오는 데이터 패킷을 어떤 프로세스나 소켓에 전달할지 결정하는 기준이다.

위가 위층이다.

| 층 | 설명 |
| --- | --- |
| 전송 계층 | 포트 번호로 프로세스 구분 |
| 네트워크 계층 | IP 주소로 호스트 구분 |

멀티플렉싱은 전송 계층에서 여러 소켓의 데이터를 모아 하나의 네트워크 인터페이스로 보내는 과정이다. 반대로 디멀티플렉싱은 수신 측에서 포트 번호를 확인하여 적절한 소켓으로 데이터를 배분하는 과정이다.

붙이지 않은 UDP 소켓은 목적지 IP와 목적지 포트만으로 구분한다. connect로 상대를 정해 두면 출발지 쪽까지 함께 본다. TCP는 4가지 요소(출발지 IP, 목적지 IP, 출발지 포트, 목적지 포트)를 모두 확인해 연결 지향적 소켓을 구분한다.
