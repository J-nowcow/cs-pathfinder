# 집 안의 여러 기기가 IP 하나로 어떻게 나가는가?

`#325` · 네트워크

나갈 때 출발지 주소를 공인 주소로 바꿔 적고 그 내역을 표에 남기기 때문이다. 포트는 겹칠 때만 바꾼다.

1. **노트북 → 공유기** — 출발지 192.168.0.3:51000
2. **공유기 → 서버** — 출발지를 공인 IP:40001로 바꿔 보낸다
3. **서버 → 공유기** — 40001로 답한다
4. **공유기 → 노트북** — 표를 보고 51000으로 되돌린다

표가 있어야 돌아온 답을 누구에게 줄지 안다. 그래서 **먼저 나간 적이 없으면 표에 줄이 없다.**

바깥에서 먼저 걸어오는 연결이 안 되는 이유가 그것이다. 받으려면 어느 포트를 어디로 보낼지 미리 적어 둬야 한다.

표의 줄은 오래 두지 않는다. 조용하면 지운다. 그래서 오래 열어 두는 연결은 주기적으로 뭔가를 보내 줄을 살려 둔다.

면접에서는 **이것이 IP 주소가 모자라 생긴 방편**이라는 점을 짚는다. 덕분에 주소를 아꼈지만 끝과 끝이 바로 닿는다는 전제가 깨졌다.
