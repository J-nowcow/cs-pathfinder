# DNS 질의 시 재귀적 질의와 반복적 질의의 차이는 무엇인가?

`#40` · 네트워크

재귀적 질의는 클라이언트가 로컬 DNS 서버에 요청을 보내고 최종적인 IP로만 답을 받는 방식이다. 반복적 질의는 로컬 DNS 서버가 직접 루트, TLD, 권한 있는 서버를 순차적으로 방문하여 답을 찾는 방식이다.

1. **클라이언트 → 로컬 DNS** — 재귀적 질의. IP로만 답하라
2. **로컬 DNS → 루트 서버** — 반복적 질의. .com의 위치를 알려달라
3. **루트 서버 → 로컬 DNS** — TLD 서버 주소
4. **로컬 DNS → TLD 서버** — 권한 있는 서버의 주소
5. **TLD 서버 → 로컬 DNS** — 권한 있는 서버 주소
6. **로컬 DNS → 클라이언트** — IP 주소 응답

재귀적 질의는 클라이언트의 부담을 줄여 단순한 결과물만 기다리게 한다. 하지만 로컬 DNS 서버가 모든 과정을 대신 수행하므로 서버의 부하가 매우 크다.

반복적 질의는 각 단계의 서버가 아는 만큼만 답한다. 최종 답을 가졌으면 그것을 주고, 모르면 더 가까운 권한 서버의 주소를 알려준다. 로컬 DNS 서버는 이 정보를 바탕으로 직접 발로 뛰며 답을 찾아내야 한다.

캐시 계층이 없다면 모든 요청이 루트 서버부터 시작되어 인터넷망의 병목이 발생한다. 이를 방지하기 위해 로컬 DNS 서버는 응답으로 받은 레코드와 TTL 값을 기준으로 정보를 저장하여 다음 요청에 빠르게 대응한다.
