# 서버 앞에 하나를 더 두는 이유는?

`#284` · 네트워크

여러 서버를 하나처럼 보이게 하고, 서버마다 하던 일을 한곳으로 모으기 위해서다.

1. **브라우저 → 리버스 프록시** — 요청을 보낸다
2. **리버스 프록시 → 앱 서버** — 살아 있는 곳을 골라 넘긴다
3. **앱 서버 → 리버스 프록시** — 응답을 돌려준다
4. **리버스 프록시 → 브라우저** — 압축하고 헤더를 붙여 준다

**브라우저는 앱 서버를 모른다.** 그래서 서버를 늘리거나 옮겨도 바깥 주소가 그대로다. 인증서와 압축, 정적 파일도 여기서 한 번에 처리한다.

방향이 반대인 것이 포워드 프록시다. 그쪽은 나가는 쪽에 서서 클라이언트를 감추고, 리버스는 들어오는 쪽에 서서 서버를 감춘다.

대신 여기가 죽으면 전부 죽는다. 그래서 이 자리도 여러 대를 두거나 앞단을 따로 둔다.
