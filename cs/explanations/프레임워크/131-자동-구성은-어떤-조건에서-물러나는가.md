# 자동 구성은 어떤 조건에서 물러나는가?

`#131` · 프레임워크

필요한 클래스가 없거나 프로퍼티 조건이 맞지 않으면 적용되지 않는다. 사용자가 같은 역할의 빈을 선언해도 기본 구성이 물러난다.

1. **앱 → 후보** — 클래스와 설정값을 검사한다
2. **후보 → 조건 평가** — 사용자 빈 유무도 확인한다
3. **조건 평가 → 빈 팩토리** — 통과한 기본 빈만 등록한다

SpringBootApplication이 EnableAutoConfiguration을 켠다. 부트는 AutoConfiguration.imports 같은 메타데이터에서 후보를 찾는다.

ConditionalOnMissingBean은 사용자 정의를 존중하는 핵심 장치다. 너무 넓은 타입의 빈을 선언하면 예상치 못한 기본 구성까지 꺼질 수 있다.

구성이 빠졌다면 조건 평가 보고서에서 일치와 불일치 이유를 확인한다. 제외 설정은 의도와 영향 범위를 알 때만 사용한다.
