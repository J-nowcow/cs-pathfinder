# 번들은 어떤 경계로 나눠 불러오는가?

`#118` · 프론트엔드

초기 경로에 필요한 코드만 먼저 보낸다. 나머지는 경로, 기능, 무거운 라이브러리 경계로 나눠 필요할 때 불러온다.

1. **초기 진입 → 핵심 청크** — 즉시 내려받는다
2. **경로 이동 → 경로 청크** — 동적으로 불러온다
3. **기능 실행 → 기능 청크** — 처음 사용할 때 불러온다

동적 import는 별도 청크를 만드는 경계가 된다. React에서는 lazy와 Suspense를 조합해 로딩 상태를 보여주며 컴포넌트를 늦게 읽는다.

너무 잘게 나누면 요청 수와 로딩 화면이 늘고 공통 모듈이 중복될 수 있다. 사용 빈도, 청크 크기, 캐시 적중률을 측정해 경계를 조정한다.
