# 화면 밖 이미지는 언제 불러와야 하는가?

`#117` · 프론트엔드

화면 밖 이미지는 사용자가 가까이 스크롤했을 때 불러온다. 첫 화면 이미지는 지연 로딩하지 않는다. 그중 LCP 후보에 높은 우선순위를 줘야 표시를 늦추지 않는다.

1. **초기 진입 → 핵심 이미지** — 즉시 요청한다
2. **관찰 영역 접근 → 화면 밖 이미지** — 다운로드를 시작한다
3. **로드 완료 → 자리 표시자** — 실제 이미지로 바꾼다

loading=lazy는 브라우저가 거리와 네트워크 상황에 따라 로드를 미룬다. 더 세밀한 제어가 필요하면 IntersectionObserver로 접근 시점을 감지한다.

이미지 공간을 미리 예약하지 않으면 로드 순간 레이아웃이 움직인다. width와 height 또는 aspect-ratio를 지정해 누적 레이아웃 이동을 막는다.
