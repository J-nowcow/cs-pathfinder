# 웹 서버와 WAS의 역할 분담은 왜 하는가?

`#239` · 프론트엔드

정적 리소스 처리 효율을 높이고 서버 부하를 분산하기 위해서다.

| 구분 | 처리 대상 |
| --- | --- |
| 웹 서버 | HTML, CSS, 이미지 등 정적 파일 처리 |
| WAS | DB 조회, 비즈니스 로직 등 동적 콘텐츠 생성 |

웹 서버가 앞단에서 정적 파일을 먼저 처리하면 WAS는 무거운 로직 수행에만 집중할 수 있다. 요청의 성격에 따라 처리 주체를 나누어 전체 응답 속도를 높인다.

또한 WAS에 장애가 발생해도 웹 서버가 에러 페이지를 대신 보여줄 수 있다. 여러 대의 WAS를 웹 서버 뒤에 배치하여 부하를 나누는 로드밸런싱 구조를 구축하기 쉽다.
