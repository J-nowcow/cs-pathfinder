# 화면이 바뀐 뒤 포커스는 어디로 보내는가?

`#121` · 프론트엔드

사용자가 다음 행동을 이해할 수 있는 지점으로 보낸다. 모달은 제목이나 첫 입력에 둔다. 닫을 때는 모달을 연 요소로 돌려보낸다.

1. **사용자 → 열기 버튼** — 모달을 연다
2. **열기 버튼 → 모달 제목** — 포커스를 옮긴다
3. **모달 → 열기 버튼** — 닫을 때 되돌린다

모달이 열린 동안 Tab 이동은 모달 안에 머물러야 한다. 배경은 키보드와 보조 기술에서 비활성화한다. Esc로 닫는 경로도 제공한다.

DOM 순서를 시각적 순서와 맞춘다. 포커스 표시를 없애지 않는다. 자동 이동은 화면 변화로 현재 맥락이 끊길 때만 사용한다.
