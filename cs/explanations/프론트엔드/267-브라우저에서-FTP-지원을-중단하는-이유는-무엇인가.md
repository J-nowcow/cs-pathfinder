# 브라우저에서 FTP 지원을 중단하는 이유는 무엇인가?

`#267` · 프론트엔드

보안 취약점과 현대적인 웹 표준의 부재 때문이다. FTP는 평문으로 주고받아 중간에서 엿보면 계정 정보와 파일 내용이 그대로 새어 나간다.

위가 위층이다.

| 층 | 설명 |
| --- | --- |
| 보안 수준 | FTP. 평문 전송. 매우 위험 |
| HTTPS | TLS 암호화. 표준으로 정착 |

또한 FTP는 방화벽과 프록시 서버 환경에서 포트 제어와 포트 범위 지정이 까다롭다. 이는 사용자 경험을 해치고 개발 효율도 떨어뜨린다.

현재는 HTTP/S 기반의 파일 업로드와 다운로드 API를 사용하는 것이 표준이다. 브라우저가 직접 FTP 프로토콜을 동작시키는 기능은 더 이상 필요하지 않다.
