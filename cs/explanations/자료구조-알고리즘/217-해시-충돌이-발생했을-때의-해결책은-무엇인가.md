# 해시 충돌이 발생했을 때의 해결책은 무엇인가?

`#217` · 자료구조 · 알고리즘

해시 충돌 해결책은 크게 체이닝과 오픈 어드레싱으로 나뉩니다. 충돌한 데이터를 저장할 공간으로 연결 리스트를 사용하거나, 빈 공간을 찾아 저장하는 방식입니다.

| 기준 | 체이닝 | 오픈 어드레싱 |
| --- | --- | --- |
| 저장 방식 | 연결 리스트 사용 | 배열 내 빈 공간 탐색 |
| 성능 저하 | 메모리 오버헤드 | 클러스터링 현상 |
| 삭제 처리 | 리스트에서 제거 | 삭제 마커로 관리 |

체이닝은 버킷에 여러 데이터를 연결해 저장한다. 데이터가 많아지면 리스트가 길어져 탐색 시간은 $O(N)$으로 늘어난다. 최근에는 리스트를 레드-블랙 트리로 바꿔 탐색 시간을 $O(\log N)$으로 줄이는 방식을 쓴다.

오픈 어드레싱은 빈 칸을 찾을 때까지 다른 칸을 탐색한다. 선형 탐색을 쓰면 데이터가 뭉치는 클러스터링이 발생해 성능이 급격히 떨어진다. 이를 막기 위해 2차 해시 함수를 쓰거나 무작위로 탐색하는 방식을 사용한다.
