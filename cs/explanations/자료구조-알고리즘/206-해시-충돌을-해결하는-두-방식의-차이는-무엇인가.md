# 해시 충돌을 해결하는 두 방식의 차이는 무엇인가?

`#206` · 자료구조 · 알고리즘

체이닝은 연결 리스트로 충돌 데이터를 쌓고, 개방 주소법은 빈 공간을 찾아 저장한다.

| 기준 | 체이닝 | 개방 주소법 |
| --- | --- | --- |
| 저장 위치 | 버킷 외부 | 버킷 내부 |
| 메모리 활용 | 추가 할당 필요 | 정해진 크기 내 활용 |
| 성능 저하 | 리스트 탐색 시간 증가 | 클러스터링 발생 |

체이닝은 데이터가 계속 늘어나도 저장 가능하며 구현이 간단하다. 하지만 데이터가 한 버킷에 쏠리면 탐색 시간이 선형적으로 증가한다.

개방 주소법은 메모리 효율이 좋으나 데이터가 찰수록 빈 칸을 찾는 비용이 크다. 특히 특정 영역에 데이터가 뭉치는 클러스터링 현상이 발생하면 성능이 급격히 떨어진다.

따라서 데이터의 양을 예측할 수 없다면 체이닝을, 메모리 공간이 한정적이라면 개방 주소법을 선택한다.
