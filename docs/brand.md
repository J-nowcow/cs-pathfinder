# 브랜드 결정

2026-08-05 확정. 근거는 아래 각 절에 남긴다.

## 이름

**`cs-pathfinder`**

pathfinding은 A\*·다익스트라를 부르는 그래프 알고리즘 정식 용어다. 동시에 "길을 개척하는 사람"이라는 여행 뜻이 있다. 우리 데이터 모델의 핵심 개념이 문자 그대로 `path`라서, 이름과 코드가 같은 단어를 쓴다.

`cs-` 접두가 도메인을 즉시 알린다. Pathfinder가 TTRPG 게임과 나사 탐사선으로 유명하지만 접두 덕에 검색에서 구분된다.

### 탈락한 후보와 이유

| 후보 | 탈락 사유 |
|---|---|
| `warren` | 굴이 이어진 망이라 의미는 최적. 한국인에게 낯설어 설명이 필요하다 |
| `rabbithole` | 굴 은유가 방향이 틀렸다. 아래로 갇히는 이미지고, 영어로는 *시간 낭비하다*라는 부정 관용구다 |
| `cs-tourist` | tourist는 겉만 훑는 사람이라는 뉘앙스다. 깊이 파는 서비스와 정반대다 |
| `cs-atlas` | 명확하지만 테크 업계에 atlas가 너무 많다 (MongoDB·Atlassian 등) |
| `tailchase` | "chasing one's tail"이 영어로 *헛수고하다*다 |
| `traverse` | 그래프 순회라 의미는 정확한데 사람 느낌이 없다 |

도메인은 사지 않는다. `*.vercel.app`을 쓴다.

## 히어로 카피

```
꼬리에 꼬리를 무는
CS 공부

하루에 질문 하나. 어디로 파고들지는 직접 고르면 돼요.
판 만큼 지도가 그려지고요.

[ 오늘 치 질문 → ]
```

제목 한 줄이 서비스 설명을 끝낸다. 그래서 **GitHub 레포 description과 히어로 제목을 같은 문장으로 쓴다.** 카톡에 링크를 붙였을 때도 이 한 줄이면 충분하다.

부제 세 문장이 각각 하나씩 맡는다. 첫 문장이 부담을 낮추고(하루 하나), 둘째가 자유를(직접 고른다), 셋째가 보상을(지도) 말한다.

CTA의 "오늘 치"는 약 복용 표현이다. 매일 하나라는 리듬을 마지막에 한 번 더 찍는다.

### 뺀 것

**면접 압박 축을 뺐다.** "면접관은 세 번째에서 멈춥니다" 같은 도발이 후킹은 세지만, 이 서비스는 시험 대비가 아니라 공부 도구다. 톤이 성격과 어긋난다.

**"지도가 남는다"를 제목에서 뺐다.** 히어로에 정보를 셋 넣으면 하나도 안 읽힌다. 지도는 배경 그래프가 시각적으로 말하고 부제 마지막 줄이 거든다.

## 카피 원칙

AI가 쓴 티를 없애는 규칙이다. 빈 상태·에러·버튼 문구까지 전부 적용한다.

- **"당신"을 쓰지 않는다.** 한국어 카피에서 번역투 신호가 가장 강한 단어다. 주어는 생략한다
- **종결어미 "~다"를 연속으로 쓰지 않는다.** "~요 / ~고요 / ~죠"를 섞는다
- **문장 길이를 일부러 어긋낸다.** 균일하면 기계가 쓴 티가 난다
- 상태 문구도 같은 톤으로 쓴다. 예: "오늘 몫은 다 쓰셨어요"

판단 기준은 `humanize-korean` 스킬의 탐지 규칙을 따랐다. 특히 A-16(대명사 직역), E-1(문장 길이 균일), E-2(동일 종결어미 연속).
